# The Loop training

Hands-on materials for The Loop at Xavier University.

## Agentic AI Literacy

[Wilson scheduler](wilson-scheduler/README.md): a fictional faculty-scheduling exercise for Claude Cowork. Download the repository ZIP, extract it, and use the wilson-scheduler folder. No Git installation is needed.

### Start with the bookstore

[Bookstore agent](bookstore-agent/README.md) is a complete fictional customer-service exercise: five emails, one order table, a supplied policy and draft replies for review. [Download the starter ZIP](https://github.com/theloopxu/training/raw/refs/heads/main/downloads/bookstore-agent.zip). No package installation or student-authored Markdown is needed.
